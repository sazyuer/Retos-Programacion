# Retos de Programación

Repositorio con retos de programación semanales y sus soluciones, en distintos lenguajes.

Cada carpeta contiene un reto independiente, con su propio enunciado, decisiones de diseño y código fuente documentados en su README.

## Retos

| # | Reto | Lenguaje | Estado |
|---|------|----------|--------|
| 1 | [Gestor de biblioteca](./RetoBiblioteca) | Java | ✅ Completado (niveles 1, 2 y 3) |

## Estructura de cada reto

- `README.md` — enunciado, decisiones de diseño y cómo ejecutar
- Código fuente del reto

## Objetivo

Practicar diseño orientado a objetos y buenas prácticas (encapsulación, polimorfismo, patrones de diseño) mediante retos semanales con comprobaciones concretas, no solo "que funcione".
